# Foundry

Internal ICT Engineering Bootcamp — two-day GitHub Foundations for M365 infrastructure engineers. AI-assisted from day one.

> **Links:** [Product Page](https://blank-look.github.io/opencode/development/products/foundry/) · [Curriculum](https://blank-look.github.io/opencode/development/products/foundry/curriculum.html) · [Q&A Bank](https://blank-look.github.io/opencode/development/products/foundry/qa.html)

## Modules

| Module | Topic |
|---|---|
| 1 | What is GitHub? Repos, branching, collaboration |
| 2 | GitHub Flow — branches, commits, pull requests |
| 3 | Markdown, docs, and wikis |
| 4 | GitHub Actions — CI/CD fundamentals |
| 5 | Secrets, environments, and security |
| 6 | Project management — issues, projects, milestones |
| 7 | Advanced collaboration — forks, code review, discussions |
| 8 | Governance, compliance, and enterprise settings |

## Format

Each module includes facilitator script, timing, prep checklist, common pitfalls, and quiz. 80% pass mark required.
