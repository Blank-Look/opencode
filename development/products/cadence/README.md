# Cadence

The human side of high performance. Rest, recovery, and creative sustainability for the engineer behind the AI.

> **Links:** [Product Page](https://blank-look.github.io/opencode/development/products/cadence/)

## Philosophy

Not more. Better. Rhythm over grind. Rest is productive. Ideas need space.

## Core Practices

1. The morning pause — silence before any screen
2. Brain break — every 90 minutes, step away
3. Movement as reset — the body leads the mind
4. The afternoon anchor — 20-minute rest
5. Close the loop — end the day with ritual
6. Weekly white space — half-day with zero obligations
