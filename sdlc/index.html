Phase 1
Capture

Capture the business requirement in a short, structured request with problem, outcome, users, systems, constraints and acceptance criteria.

→ Phase 2
Govern

Identify applicable policies, data classifications, security standards and agent permissions before information is provided to AI.

→ Phase 3
Generate

Use ChatGPT with a standard template to produce a controlled OpenCode delivery prompt covering scope, tests, security and approvals.

→ Phase 4
Build

OpenCode creates application code, tests, infrastructure, documentation and deployment definitions within an approved repository.

→ Phase 5
Assure

Code moves through AI Workspace, Sandbox, Development and Test environments with progressively stricter controls and checks.

→ Phase 6
Release

Azure DevOps orchestrates CI/CD from pull request through sandbox, development, test and production with approval gates.

→ Phase 7
Operate

Production verification, monitoring, incident response, vulnerability management, access reviews and continuous improvement.
