Minimum Security Standards: Cookbooks

The cookbooks below are step-by-step guides to simplify adoption of the Minimum Security Standards on Moderate or High Risk servers.

Endpoints Servers Applications SaaS/PaaS IaaS IoT Definitions Cookbooks FAQ Inquiries

Windows Servers

  1. Complete a Data Risk Assessment.
  2. Install the endpoint management agent for servers.
    1. Subscribe to the service as an administrator.
    2. Install the agent for Windows servers.
  3. Install the centralized logging forwarder.
    1. Request a logging account.
    2. Install the logging forwarder for Windows servers.
  4. Request a Privileged Access Workstation (PAW).
    1. PAWs are only required for administering High Risk servers and applications.
  5. Install two-step authentication for servers.
    1. Request your API keys and service hostname.
    2. Deploy two-step authentication for remote desktop on your systems.
  6. Install the anti-malware agent.
    1. Request an account.
  7. Configure your host-based firewall.
    1. Configure your firewall in default-deny mode, and permit only the minimum necessary services.
  8. Regularly scan for vulnerabilities with the approved vulnerability scanning service.
    1. Request a scanning account.
    2. Sign in to the scanning console to manage custom scans and reports.
  9. Review your compliance with the remaining standards.
    1. Apply high severity security patches within seven days of publish, and all other security patches within 90 days.
    2. Review and update your system inventory records quarterly.
    3. Enforce password complexity requirements and review your existing admin accounts and their privileges.
    4. Physically protect your server.
    5. Implement applicable regulatory controls.
