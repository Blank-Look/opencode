SharePoint Governance Manager

Automated governance scanning for SharePoint Online — external sharing audit, owner validation, inactivity detection, and lifecycle management.

Overview

SharePoint Governance Manager provides continuous visibility into the health and compliance of every SharePoint site, Teams-connected team site, and communication site. It scans via Microsoft Graph API, detects governance gaps, and surfaces them in a structured queue — without modifying any site settings or requiring agent installation.

Architecture

Architecture docs → Microsoft Graph API, Governance Scanner, SharePoint List queue, and Power BI dashboard. Read-only scanning, no write-back, no agents.

Governance Detection Rules

RuleDetectionSeverity
External SharingSite allows sharing with anyone, new/existing guests, or anyone in the organisationHigh
No Site OwnerSite has no owners, or all owners are inactive/disabledCritical
Inactive SiteNo activity for 90+ days (configurable threshold)Medium
Broken InheritanceUnique permissions that don't inherit from parentWarning
Sensitive Content OversharedSite with sensitive/confidential content has external sharing enabledCritical
Large SiteSite exceeds storage threshold (default 25 GB)Info
Orphaned SiteTeams-connected site where the team has been deleted but site remainsHigh

Lifecycle Management

StageDescription
ActiveSite is in use with valid owners and acceptable governance posture
ReviewSite flagged for governance issue — owner notified
ArchiveSite inactive for extended period — content preserved, access restricted
DeleteSite approved for removal — retention period enforced

Security & Compliance

Read-only Microsoft Graph permissions. No write-back to SharePoint sites. All governance data stored in a single SharePoint list with audit logging. Site content is never accessed — only metadata, permissions, and activity data.
