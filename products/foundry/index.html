Curriculum

Self-paced.

Module 1 30 min

Why GitHub?

Why not SharePoint? Git vs GitHub. Repositories, Markdown, Pull Requests, GitHub Actions, AI integration.

  • Quiz: 5 questions · 80% pass
Module 2 1 hour

Markdown

Headings, lists, tables, links, images, Mermaid diagrams, code blocks. Hands-on from the start.

  • Exercise: Create a README.md for an Intune application
  • Quiz
Module 3 2 hours

Git Basics

Clone, status, add, commit, push, pull. Working copy → Commit → Repository → Remote.

  • Exercise: Everyone edits the same repository
  • Quiz
Module 4 2 hours

Branches & Pull Requests

Create branch → Edit → Commit → Push → PR → Review → Merge. Including merge conflicts — everyone resolves one.

  • Exercise: Cross-team PR with conflict resolution
  • Quiz
Module 5 1 hour

Repository Standards

README, docs/, scripts/, .github/, LICENSE, CODEOWNERS. How to structure every repo consistently.

  • Exercise: Build a repository from scratch
Module 6 1 hour

GitHub Actions

Just enough to understand. Push → workflow starts → tests → deploy docs. No deep YAML.

  • Exercise: Push markdown, Action builds MkDocs, site updates
Module 7 1 hour

AI

ChatGPT, Copilot, OpenCode, Claude Code — using AI to generate READMEs, improve Markdown, write PowerShell, explain scripts, review PRs, and generate workflows.
Module 8 30 min

Engineering Standards

How your organisation will work. Repository naming, PRs, reviews, Issues, Projects, documentation, branch protection.
