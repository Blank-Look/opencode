Module 7: AI

ChatGPT, Copilot, OpenCode, Claude Code — generating docs, writing PowerShell, reviewing PRs, building workflows.

Self-paced · ~45 min

Read

AI tools overview

AI tools are part of the engineering workflow now. They generate, suggest, and automate. The skill is knowing how to prompt them and when to trust the output.

  • ChatGPT: Best for generating Markdown, PowerShell scripts, and explaining code. Prompt in natural language, review the output, commit.
  • Copilot: Best for inline completions while typing in VS Code. Start typing a comment or function name, Copilot suggests the rest.
  • OpenCode / Claude Code: Terminal-based agents. Describe what you want, they build files, run commands, commit changes.

Golden rule: AI generates. Humans approve. Never commit AI output without reading it first. AI can hallucinate commands, flags, and APIs. You are responsible for every line that goes into the repository.

Try ChatGPT

Open ChatGPT (or your preferred chat AI) and try these prompts:

  • "Write a README.md for an Intune application packaging repository. Include a table of supported applications with App Name, Version, Platform, and Status columns. Include instructions for requesting a new package."
  • "Write a PowerShell script that exports all Intune compliance policies to CSV."
  • Paste a complex script from your repo and ask it to explain what it does.

Copy the output, review it for correctness, adjust as needed, and commit it to a practice repo.

Try Copilot

Open VS Code with Copilot installed. In a new PowerShell file, type:

# Function to get all Intune devices and export to CSV

Copilot will suggest the function body. Press Tab to accept. Try writing comments describing a function and watch Copilot complete it. Then try refactoring a function by describing what you want in a comment.

Try an AI coding agent

If you have OpenCode or Claude Code installed, try this prompt in your terminal:

  • "Create a GitHub Actions workflow that runs on push to main, builds MkDocs documentation, and deploys to GitHub Pages."
  • "Create a .github/workflows/ci.yml that runs PowerShell linting on push."

Let the agent create the file, then review every line before you commit. Never approve changes you don't fully understand.

Try AI-assisted PR review

Open a pull request in one of your repositories. Copy the diff and paste it into ChatGPT with this prompt: "Review this PR for errors, style issues, and security problems." Compare the AI's feedback with your own analysis. Does it catch everything you see? Does it flag anything you missed?

Self-paced practice

Work through each of these four exercises on your own:

Exercise 1: ChatGPT

Generate a README. Improve existing Markdown. Write a PowerShell script. Ask it to explain a complex script from your repo.

Exercise 2: Copilot

Open VS Code with a PowerShell file. Write comments describing a function. Accept completions. Try refactoring a function.

Exercise 3: AI Agent

Run OpenCode or Claude Code. Prompt: "Create a .github/workflows/ci.yml that runs PowerShell linting on push." Review the output before accepting.

Exercise 4: PR Review

Open a PR in your repo. Paste the diff into ChatGPT. Ask: "Review this PR for errors, style issues, and security problems."

Common pitfalls

  • Blind acceptance: AI generates plausible-sounding but wrong code. Always test or review before committing.
  • Hallucinated commands: AI invents PowerShell flags and API endpoints that don't exist. Verify against documentation.
  • Secrets in prompts: Never paste API keys, passwords, or sensitive data into ChatGPT or any AI tool.
  • Over-reliance: AI is a productivity tool, not a replacement for understanding. Know enough to judge the output.
