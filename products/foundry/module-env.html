Curriculum 2 · ~45 min — self-paced

Your AI Development Toolchain

This module walks through the tools you'll use day-to-day when building with AI assistance: OpenCode, VS Code, Git, and the configuration files that connect them. By the end you'll have a working environment and understand how each piece fits together.

What you'll learn

  • Set up OpenCode and connect it to your repository
  • Configure VS Code for AI-assisted development
  • Understand how AGENTS.md guides AI behaviour
  • Clone a repo, configure your editor, and run your first AI-assisted task

OpenCode — the AI agent in your terminal

OpenCode is a CLI tool that sits in your terminal and works with your Git repository. You give it a task, it reads your files, writes code, runs commands, and commits changes. It reads AGENTS.md at the root of your repo to understand conventions, constraints, and preferred workflows.

Key commands:

opencode          # Start interactive session
opencode "task"   # Run a specific task
opencode --help   # See all options

VS Code — your editor with AI superpowers

VS Code with the Copilot extension gives you inline code completion, chat-based AI assistance, and integrated terminal access. OpenCode works alongside it — you write in VS Code, run OpenCode in the terminal below.

Recommended extensions for AI-assisted development:

  • GitHub Copilot — inline completions and chat
  • Markdown All in One — table of contents, formatting, preview
  • YAML — validation and syntax highlighting for workflows
  • Mermaid Preview — diagram rendering in the editor

AGENTS.md — the instruction file AI reads first

Every SchoolCode product includes an AGENTS.md file at the repository root. This file tells AI tools — OpenCode, Claude Code, Copilot — about the project: its structure, conventions, commands, and constraints. When you run OpenCode in a repo with AGENTS.md, it reads that file automatically and adapts its behaviour.

A typical AGENTS.md covers:

  • Project structure — which directories contain what
  • Workflow commands — how to run tests, build, lint
  • Conventions — naming patterns, coding style, comment styles
  • Constraints — what the AI should avoid doing
Exercise — Explore AGENTS.md

Open the AGENTS.md file at the root of this repository. Read through each section. Then ask OpenCode: "What is the purpose of this repository according to AGENTS.md?" — notice how it uses the file to answer.

Connecting your editor to Git

Before AI tools can work, your editor needs to be connected to the repository. The setup is straightforward:

# Clone the repository
git clone https://github.com/Blank-Look/opencode.git

# Open in VS Code
code opencode

# Verify Git is configured
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

Running your first AI-assisted task

Once OpenCode is installed and the repo is cloned, start with something small:

opencode "Summarise the contents of products/foundry/ in a few sentences"

This verifies OpenCode can read files, understand context, and respond. From here you can escalate to generation tasks — always with review.

Exercise — First AI Task

Run OpenCode from the repository root. Ask it to: "List all module files in products/foundry/ and create a markdown table showing each module number, title, and estimated time." Review the output, then commit if it looks right.

Configuring OpenCode for your project

OpenCode can be configured per-project with an opencode.json or .opencode/ directory at the repository root. This file sets custom instructions, API keys, agent behaviour, and permissions. Check your project's AGENTS.md for any OpenCode-specific setup instructions.

Key takeaways

  • OpenCode is the CLI agent — reads AGENTS.md, operates in your repo
  • VS Code + Copilot gives inline AI assistance while you edit
  • AGENTS.md is the single source of truth for AI behaviour in a repo
  • Git connection is the foundation — AI tools work with what Git tracks
  • Always review AI output before committing. AI generates, you approve.
